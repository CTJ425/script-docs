## 這個站

ivan note 是我的個人資訊部落格。它不是一份教學大全，只是我自己的記錄：寫過的 script、用過的工具、放在 GitHub 上的專案，以及中間踩過的坑。

## 內容怎麼來

站上有三種內容：

- **文章**：依時間排列的筆記，一篇講一件事。
- **工具**：用過的工具。每一項標明現在是使用中、試過，還是已經淘汰，並用一句話寫下結論。
- **腳本**：我寫的 script。每一頁都是該資料夾 `README.md` 的原文，所以網站上看到的和 GitHub 上看到的是同一份。

整個站的內容都放在同一個 [GitHub repo](https://github.com/CTJ425/script-docs) 裡，網站是從那些檔案直接產生的，沒有另一份副本。
